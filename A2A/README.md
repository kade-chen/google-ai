A2A 演示demo(python)
===================
## 1. 简介
A2A 演示demo(python) 是基于python语言实现的A2A协议的演示demo，用于演示A2A协议的通信过程。
## 2. 功能
A2A 演示demo(python) 实现了A2A协议的通信过程，包括A2A协议的初始化、A2A协议的连接、A2A协议的断开连接、A2A协议的数据发送和接收等功能。
## 3. 使用方法
A2A 演示demo(python) 的使用方法如下：
1. 安装python环境 >= 3.10
2. cd A2A/app
3. 创建虚拟环境 python -m venv .venv
4. 激活虚拟环境 source .venv/bin/activate
5. 安装依赖 pip install -r requirements.txt
